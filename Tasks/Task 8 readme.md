Customer Segmentation using K-Means Clustering
Description
This notebook performs customer segmentation on a dataset using the K-Means clustering algorithm. It includes data preprocessing to handle missing values, selecting relevant features, fitting the K-Means model, and evaluating clusters using the silhouette score metric.

Features
Loads customer segmentation data.

Preprocesses data by handling missing values.

Applies K-Means clustering with configurable cluster count.

Calculates and displays the silhouette score to evaluate clustering quality.

Outputs cluster labels and centroids for interpretation.

Usage
Run the notebook in a Python environment such as Anaconda with necessary packages installed (pandas, scikit-learn, tabulate). Ensure the customer dataset CSV is accessible in the working directory.
